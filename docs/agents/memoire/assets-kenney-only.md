When the CDP-2026 game needs new assets, take them only from the Kenney site (kenney.nl); never download assets from anywhere else. Sounds generated by the repo's own script (frontend/tools/generate_sounds.py) are fine.

**Why:** the user said so explicitly (2026-11-03); Kenney assets are CC0, which keeps LICENCES.md simple and safe.
**How to apply:** prefer the kits already in frontend/assets/models/kenney; if one is missing, fetch it from kenney.nl, store it the same way and add it to LICENCES.md and docs/assets.md. Related: [[game-context]].
